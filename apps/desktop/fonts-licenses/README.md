# Bundled font licences

The desktop renderer embeds two font families as base64 `woff2` data URIs in
`src/renderer/fonts.css`, `src/renderer/first-run/_fonts.css` and
`design/_fonts.css`. Both are licensed under the SIL Open Font License 1.1,
which requires the licence to travel with the fonts:

| Family | Licence | Copyright | File |
|---|---|---|---|
| Archivo | OFL-1.1 | 2020 The Archivo Project Authors | `Archivo-OFL.txt` |
| IBM Plex Mono | OFL-1.1 | 2017 IBM Corp., Reserved Font Name "Plex" | `IBMPlexMono-OFL.txt` |

Source of the licence texts: `github.com/google/fonts` (`ofl/archivo/OFL.txt`,
`ofl/ibmplexmono/OFL.txt`).
