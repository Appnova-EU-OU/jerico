# Jerico

**AI Agent Control Center** — orchestrate multiple AI coding agents (Claude, Qwen, Kimi, Codex and more) across all your projects from a single native macOS app. Plan, dispatch, review and ship — with live multi-agent panels, per-project context, and a built-in Bridge MCP toolset.

## ⬇ Download

**macOS (Apple Silicon / M-series):** grab the latest **`.dmg`** from the
**[Releases page →](https://github.com/Appnova-EU-OU/jerico/releases/latest)**

Open the downloaded `jerico-<version>-arm64.dmg`, then drag **Jerico** into your **Applications** folder.

> Requires macOS on Apple Silicon (M1 or newer). Intel/Universal builds are on the roadmap.

## Features

- **Multi-agent orchestration** — run and coordinate several AI coding agents side by side.
- **Project-first workspace** — every project shows its live agents, plan, todos and execution at a glance.
- **Bridge MCP** — 45+ built-in tools that let agents query and act on your workspace.
- **Live ops console** — real-time agent status, panels and machine health.
- **Automatic updates** — in-app Software Update keeps you on the latest version.
