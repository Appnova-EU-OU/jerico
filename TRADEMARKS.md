## What you may do without asking

- Refer to Jerico by name to describe it truthfully: "works with Jerico",
  "a plugin for Jerico", "based on the Jerico client", in articles, talks,
  documentation, package descriptions and comparisons.
- Keep the name where the code itself uses it (package names, identifiers,
  configuration paths) when you build or modify this code for your own use.

Do not use the name or logo in a way that suggests Appnova EU OÜ made,
endorses or supports something it did not.

## Forks and redistributed builds

If you distribute a modified version — a fork, a repackaged app, a build
published under your own account — give it a different name and replace the
app icon and logo (`apps/desktop/build/`, `apps/desktop/brand/`). You may say
it is "based on Jerico" or "a fork of Jerico".
